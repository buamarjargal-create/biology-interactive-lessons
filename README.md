# Биологийн интерактив хичээлүүд

Ерөнхий боловсролын сургуулийн биологийн хичээлд зориулсан, багш өөрөө удирддаг интерактив үзүүлэн хуудсууд.

| Хавтас | Хичээл |
|---|---|
| [`salst-sormuus/`](salst-sormuus/) | 10.4.2в · Салст ба сормуус: бидний хамгаалагчид |
| [`esiig-hemjih/`](esiig-hemjih/) | 11.3г · Эсийг хэмжих |

## Бүтэц

Хичээл бүр гурван файлтай:

- `index.html` — хуудасны бүтэц
- `style.css` — загвар, өнгө
- `app.js` — алхмууд, хөдөлгөөн, удирдлага

## Ашиглах

1. Хичээлийн хавтас доторх `index.html`-ийг Chrome-оор нээнэ.
2. **🖥 Проектортой хичээл эхлүүлэх** товчийг дарна. Проектор дээр сурагчдын дэлгэц, багшийн компьютер дээр илтгэгчийн харагдац (тэмдэглэл, хариу) гарна.
3. Проектор холбоогүй бол **Энэ дэлгэцээр л үзүүлэх** товчийг дарна.

Юу ч өөрөө тоглохгүй, бүх зүйл багшийн товч дарахад л явна.

## Гарын товч

| Товч | Үйлдэл |
|---|---|
| → / PageDown | Дараагийн алхам |
| ← / PageUp | Өмнөх алхам |
| Space | Тоглуулах / зогсоох |
| 1–5 | Тухайн алхмын үйлдлүүд |
| B | Дэлгэцийг харлуулах |
| N | Тэмдэглэл нээх / хаах |
| F | Бүтэн дэлгэц |

Проектор горим (хоёр цонх) нь `BroadcastChannel`-аар хоорондоо холбогддог тул хоёр цонх нэг хөтөч дээр, нэг файлаас нээгдсэн байх ёстой.
